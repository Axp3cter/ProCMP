<h1 align="center">ProCMP</h1>

<p align="center">Bundle one Luau source tree into many build targets from a single manifest.</p>

---

```sh
rokit add Proton-Utilities/ProCMP
pcmp init
pcmp build
```

Links in [darklua](https://darklua.com) as a library.
